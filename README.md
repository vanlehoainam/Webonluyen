# 🚗 Ôn Luyện & Thi Thử GPLX 2026

Dự án web hỗ trợ ôn luyện, thi thử lý thuyết, sa hình và đường trường theo **Thông tư 108/2026/TT-BCA** của Bộ Công an.

## 📁 Cấu trúc thư mục

```
gplx-2026/
├── index.html          # Trang chính
├── css/
│   └── style.css       # Toàn bộ CSS
├── js/
│   └── app.js          # Logic JavaScript (câu hỏi, thi thử, navigation...)
├── assets/             # Thư mục chứa hình ảnh (nếu cần mở rộng)
└── README.md           # File này
```

## ✨ Tính năng

| Mục | Mô tả |
|-----|-------|
| **Trang chủ** | Tóm tắt quy định mới 2026 (bỏ mô phỏng, thi tuần tự, cấu trúc đề...) |
| **Ôn lý thuyết** | Ôn theo 6 chương + nhóm câu điểm liệt (mẫu) |
| **Thi thử** | Đúng cấu trúc hạng B: 30 câu / 20 phút / đạt ≥27 + không sai điểm liệt |
| **Mô phỏng** | Hướng dẫn & mẹo (đã bỏ khỏi sát hạch từ 01/7/2026) |
| **Sa hình** | Chi tiết 11 bài + lỗi trừ điểm / truất quyền |
| **Đường trường** | Checklist & các lỗi dễ bị đình chỉ |

## 🚀 Cách chạy

1. Mở file `index.html` bằng trình duyệt (Chrome, Edge, Firefox...).
2. Hoặc dùng live server nếu muốn:

```bash
# Ví dụ với Python
cd gplx-2026
python -m http.server 8080
# Sau đó mở http://localhost:8080
```

## 📌 Lưu ý quan trọng

- Bộ câu hỏi trong dự án là **mẫu tự biên soạn** mang tính chất tham khảo, không sao chép nguyên văn ngân hàng 600 câu chính thức của Cục CSGT.
- Để ôn đầy đủ, nên kết hợp với tài liệu/phần mềm chính thức từ trung tâm đào tạo.
- Từ **01/3/2027**: Hạng B sẽ chuyển sang 50 câu / 33 phút / đạt 45 câu.
- Hiện tại (11/2026): Vẫn dùng cấu trúc 30 câu.
